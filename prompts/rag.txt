# EXPERIMENT: RAG CONDITION

## Role
You are a Cyber Threat Intelligence (CTI) analyst.

## Objective
Produce a structured threat profile of Salt Typhoon (MITRE ATT&CK G1045).

## Experimental condition
This is a RETRIEVAL-AUGMENTED GENERATION (RAG) experiment.
You are provided with a reference corpus.
Base your claims on the supplied evidence passages only.

## Evidence corpus
{{EVIDENCE_PASSAGES}}

## Instructions
Analyze the following categories:
1. Objectives and intentions
2. Capabilities
3. Resources and organization
4. Targeted sectors and organizations
5. MITRE ATT&CK tactics and techniques (TTPs)
6. Attribution and confidence

Generate approximately 30 atomic claims.
Each claim must express one main factual statement.
Avoid combining independent facts.

Apply these precautions:
- Distinguish confirmed facts from assessments and assumptions.
- Preserve uncertainty in attribution.
- Do not assume actor names or aliases refer to the same entity.
- Distinguish direct Salt Typhoon activity from associated actor activity.
- ATT&CK technique associations do not prove use in every incident.
- Distinguish observed activity from possible capabilities.
- A known vulnerability is not automatically a zero-day.
- Do not invent details to fill gaps.
- If uncertain, explicitly indicate that uncertainty.
- Do not present assumptions as established facts.

For every claim:
- Cite the exact passage IDs that support it.
- Do not invent passage IDs or citations.
- Do not cite a passage unless it genuinely supports the claim.
- Do not present unsupported information as established fact.

## Allowed categories
Use exactly one:
- objectives
- capabilities
- resources
- targets
- TTPs
- attribution

## Confidence levels
Use exactly one:
- certain
- likely
- possible
- unknown

## Output format
Return ONLY valid JSON.
No Markdown fences or additional explanations.

{
  "group": "Salt Typhoon",
  "condition": "rag",
  "claims": [
    {
      "claim_id": "RAG-001",
      "category": "objectives",
      "claim": "One factual statement.",
      "confidence": "likely",
      "evidence_passage_ids": ["S03-P02"],
      "support_note": "Brief note explaining how the cited evidence supports the claim."
    }
  ]
}

## Important
- Use unique IDs starting with RAG-001.
- Use only the six allowed categories.
- Cite only passage IDs that exist in the supplied corpus.
- Do not cite a passage unless it genuinely supports the claim.
- Return approximately 30 claims.
- Return valid JSON only.
