# EXPERIMENT: CLOSED-BOOK CONDITION

## Role
You are a Cyber Threat Intelligence (CTI) analyst.

## Objective
Produce a structured threat profile of the cyber threat group
Salt Typhoon (MITRE ATT&CK G1045).

## Experimental condition
This is a CLOSED-BOOK experiment.

You must rely only on the knowledge available to you.
You are NOT provided with reference documents or evidence passages.
Do not browse the internet or claim to have consulted external sources.

## Instructions
Analyze the following categories:

1. Objectives and intentions
2. Capabilities
3. Resources and organization
4. Targeted sectors and organizations
5. MITRE ATT&CK tactics and techniques (TTPs)
6. Attribution and confidence

Generate approximately 30 atomic claims.

Each claim must express one main factual statement.
Avoid combining several independent facts in one claim.

Be careful with:
- Uncertain or disputed attribution.
- Differences between actor names and aliases.
- The distinction between confirmed facts and assessments.
- The difference between observed activity and possible capabilities.
- The distinction between zero-day exploitation and exploitation of known vulnerabilities.

Do not invent details to fill gaps.
If you are uncertain, explicitly indicate that uncertainty.
Do not present assumptions as established facts.

## Allowed categories
Use exactly one of these values:
- objectives
- capabilities
- resources
- targets
- TTPs
- attribution

## Confidence levels
Use exactly one of these values for each claim:
- certain
- likely
- possible
- unknown

## Output format
Return ONLY valid JSON.
Do not use Markdown code fences or additional explanations.

Use this exact structure:

{
  "group": "Salt Typhoon",
  "condition": "closed_book",
  "claims": [
    {
      "claim_id": "CB-001",
      "category": "objectives",
      "claim": "One factual statement.",
      "confidence": "likely",
      "evidence_passage_ids": [],
      "reasoning": "Brief explanation of the basis or uncertainty."
    }
  ]
}

## Important
- Use unique claim IDs starting with CB-001.
- Use only the six categories listed above.
- Keep evidence_passage_ids as an empty array.
- Do not fabricate citations or passage IDs.
- Return approximately 30 claims.
- Return valid JSON only.
